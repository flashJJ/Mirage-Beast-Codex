## 3. 建议顺序（2026-10-06 更新：F1~F3/F4/F5/F7 已全部完成）

```
【已完成】F1~F3 → F4/F5/F7 → 2D 化（8 只立绘 + 打击动效）
                    │
        ┌───────────┼────────────────────────┐
        ▼           ▼                        ▼
   ① F43 数值模型   ② F9 发布上线          ③ F8 存档
   （乘性减伤）    （压缩+itch.io+README）  （10 h）
        │           │                        │
        └───────────┴────────────┬───────────┘
                                 ▼
                    【分叉】A) F15 AI 战败教练（50 h，AI 岗位差异化）
                            B) F19~F22 世界探索最小切片（66 h，兑现开放世界标签）
                                 ▼
                      F23~F29 → F30~F36 → F37~F41
```

**为什么是这个顺序**：

1. **F43 先做** —— 现在只有 8 张卡，改伤害模型只需重算 8 张；等做了 20 只 + 世界 + 副本再改，
   就是几十个 JSON 全量返工。等级悬崖（1 级差 = 49 个百分点胜率）是结构问题，调数字糊不过去。
2. **F9 发布优先于"做更多功能"** —— 求职阶段，**一个能点开就玩的在线链接 > 再多两个未发布的功能**。
   当前包体 34 MB，gzip/brotli 后约 10 MB，itch.io 可直接托管，成本约 9 h。
3. **F8 存档** —— M2 最后一块拼图，10 h，做完才算"完整可玩版本"。
4. **分叉 A vs B** —— 见 §5 Q7。默认推荐 **A（AI 战败教练）**：
   你主投的是 *AI 应用* 岗，"游戏 + 本地大模型"的组合在简历里的辨识度远高于"又一个小体量 2D 游戏"；
   且 F15 只需 F3 战报（已完成）+ F10~F14 最小实现，50 h 可控。
5. **不要一次性承诺 M3~M5** —— 那仍是 770 h（14 个月），做完 V0 后再评估。

## 4. 明确不做（防膨胀）

| 不做 | 理由 |
|---|---|
| LLM 做出牌决策 | 延迟毁节奏 + 破坏确定性 + 规则 AI 更优 |
| 玩家自由文本输入 | 内容安全不可控 |
| 联网 / 服务端 / 账号 | 单机定位 |
| 付费 / 内购 / 广告 | 作品集定位 |
| PVP / 排行榜 / 赛季 | 改为 AI 试炼塔 |
| 移动端适配 | 资源有限 |
| 配置可视化编辑器 | 手写 JSON 足够（20~30 张卡） |
| 多语言 | 作品集阶段不需要 |

**新想法一律先写进本文件"待评估"，搁置 ≥2 周后再决定，且必须从其他任务等量扣除工时。**
