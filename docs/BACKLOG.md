## 3. 建议顺序（考虑求职时效）

```
F1 Web导出验证 ──► F2 单元测试 ──► F3 结构化战报
                                        │
                        ┌───────────────┴───────────────┐
                        ▼                               ▼
              F4~F9 战斗 UI → 【发布 V0】       F15 战败复盘教练（AI）
                        │                               │
                        └───────────────┬───────────────┘
                                        ▼
                              F19~F29 世界探索
                                        ▼
                              F30~F36 内容量产
                                        ▼
                              F37~F41 打磨
```

**关键建议**：

1. **F1 优先于一切** —— 若 Web 导出不通，作品集策略要改为"Windows 下载版 + 录屏"，而现在知道比 4 个月后知道便宜得多。
2. **F2 + F3 现在做** —— 模拟已跑通，是加测试和结构化日志的最佳时机，晚做必返工。
3. **M2 发布 V0 后，先做 F15（AI 战败教练，约 50 h）再做世界** —— 理由：`gdd/13` §9.3，求职时效（6~7 个月有"游戏+AI"作品 vs 18+ 个月），且差异化价值不成比例地高。
4. **不要一次性承诺 M3~M5** —— 那是 770 h（14 个月），做完 V0 后再评估。

## 4. 明确不做（防膨胀）

| 不做 | 理由 |
|---|---|
| LLM 做出牌决策 | 延迟毁节奏 + 破坏确定性 + 规则 AI 更优 |
| 玩家自由文本输入 | 内容安全不可控 |
| 联网 / 服务端 / 账号 | 单机定位 |
| 付费 / 内购 / 广告 | 作品集定位 |
| PVP / 排行榜 / 赛季 | 改为 AI 试炼塔 |
| 移动端适配 | 资源有限 |
| 配置可视化编辑器 | 手写 JSON 足够（20~30 张卡） |
| 多语言 | 作品集阶段不需要 |

**新想法一律先写进本文件"待评估"，搁置 ≥2 周后再决定，且必须从其他任务等量扣除工时。**
